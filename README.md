# Life & Wealth Dashboard

A visual long-range planning simulator for career income, savings, investing, real estate, rental cash flow, and major life milestones.

## Current MVP

- Black/red liquid-glass dashboard design
- Conservative, realistic, and ambitious scenarios
- Editable assumptions saved locally in the browser
- Net-worth projection chart
- Household-income chart
- Rental portfolio value and debt chart
- Monthly rental cash-flow chart
- Age-50 asset allocation view
- Milestone timeline
- Financial guardrails
- Responsive layout for desktop and mobile

## Important

The numbers in this project are planning assumptions, not financial, legal, tax, military-career, mortgage, or investment guarantees. The model is intentionally editable. Before using a number for a real decision, replace estimates with current authoritative figures and professional guidance where appropriate.

## GitHub Pages

This project is intentionally static (`index.html`, `styles.css`, and `app.js`) so it can be hosted directly with GitHub Pages without a build step.

In the repository settings, open **Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
