# V2.1.1 Templates and first run

Four first-run choices create nothing on load: Planning Template, Scratch, Example, Import. Template and scratch are unsaved candidates. Cancel restores the full previous session; replacing an existing plan requires an explicit in-page confirmation before normal persistence. Reset continues to create the canonical baseline.

The template keeps birth timing, balances, BAH, debt information, filing status, and transfer timing unresolved. Education/cohort intentions are descriptive. JAG and pediatrics dates are materialized as editable July planning dates only after birth timing is supplied. JAG planned service assumes no prior service and is explicitly labeled for review. Physician residency uses the supported PGY1–3 dataset roles. No home purchase age is fixed. The $1.5M target uses 2025 purchasing power. A $200,000 expected property transfer remains metadata, not current wealth. Combining finances at about 29 and later civilian work remain optional intentions. No fixed gross-income savings formula is introduced.

Template Review consumes production structured readiness. Military BAH remains required when entering the dated military stage. Six-month household reserves and separate investment accounts are preserved. Planning assumptions have embedded template provenance.

The fictional Alex/Jordan example runs the production engine for 2026–2065. It purchases a primary home in 2033, converts it to rental in 2040, receives an expected property transfer in 2044, and evaluates a real long-term-home goal. It is temporary, with a banner on every view. Editor and persistence actions are blocked. Entry/exit preserve saved plan, backup, unsaved draft, import candidate, recovery state, selected year and route; exit without a plan restores onboarding. Navigation and age changes do not rerun simulation.

Validation: 315 tests pass including eleven new onboarding/session regressions and the military/finite-output suites. Local HTTP and all seven example views were checked in the in-app browser without captured console errors. Mobile 390x844 layout and keyboard Enter/age-arrow interactions were checked. Saved-plan exit restoration and explicit replacement confirmation were exercised. Native browser confirmation was replaced by an in-page confirmation for this new workflow after the native dialog stalled the test browser. Existing import/recovery unit regressions pass; broader hands-on UAT remains required. V1 root remains byte-identical.
