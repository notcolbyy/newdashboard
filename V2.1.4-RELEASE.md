# V2.1.4 — Life Plan first-run usability

V2.1.4 changes the recommended Life Plan entry from a technical readiness form to one timing question followed by the real Overview.

- Birth year is the only required first-run answer because it anchors age-based stages to calendar years.
- Filing status, military housing allowance, opening balances, and the partner path enter through the production model as editable `planningDefault` assumptions with provenance.
- Computational opening balances are explicitly labeled as placeholders; the UI continues to say that current finances and debt have not been added.
- The exploratory Life Plan is session state and is not saved automatically. Existing-plan replacement confirmation, example isolation, imports, backups, and canonical Reset remain unchanged.
- Overview now exposes current-finance personalization, planning-assumption review, and deterministic life-stage observations alongside authoritative financial output.

Financial versions remain engine v2.0.3, model/schema 2.0.0, and output contract 2.0.2. UI assets are revision 2.1.9. V1 remains the root application.
